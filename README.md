# Ekeh Precious Maro – Portfolio (React + Vite + Tailwind)

    npm install
    npm run dev       # local preview
    npm run build     # production build in /dist

- **All copy, links, projects, achievements** live in `src/data/content.js`.
- Put the approved portrait in `/public` and set `profile.portrait` (e.g. `'/portrait.jpg'`).
- Forms: create a `.env` with `VITE_FORM_ENDPOINT=<your Formspree/Getform/API URL>`. Without it, submissions are simulated.
